Layer 1

The Foundation

Forked Batocera Linux. Kernel, drivers, emulator backends. The default frontend never boots.

Layer 2

The Bridge

Python service daemon. Launches cores, syncs saves, monitors streaming health. FastAPI over Unix sockets.

Layer 3

The Face

Godot 4 dashboard. Six Memory Cards, ambient particles, original glyphs and motion. The whole experience.
