# Contributing to VetTV: Memory Card Edition

Thanks for taking an interest. VetTV MCE is in **Phase 0 — Toolchain Verification** as of April 2026. Outside contribution is not yet open at the code level — the project is single-maintainer until at least Phase 5.

What *is* welcome right now:

- Issue reports for documentation gaps, IP-hygiene risks, or hardware-tier edge cases
- Discussion in pinned issues during phase milestones
- Beta interest signals — the **First Card Holders** beta opens at Phase 6

## Before opening anything

1. Read `README.md` for project identity and current phase
2. Read `docs/01_VetTV-MCE-Blueprint.md` — the master blueprint
3. **Read `docs/02_IP-Hygiene-Rules.md`** — non-negotiable. Anything that risks the IP firewall gets closed.

## Issues

- Use the templates in `.github/ISSUE_TEMPLATE/`
- One issue per concern — don't bundle
- For IP-hygiene concerns, use the **IP hygiene flag** template and tag the issue `ip-hygiene` — those get triaged first

## Pull requests

- Will open up at Phase 5 (Polish & Content Layers) for theme/asset contributions
- Until then, PRs from outside the maintainer will be closed politely with a pointer to this document
- The PR template applies once PRs are open

## Code of conduct

`CODE_OF_CONDUCT.md` applies to all repo interactions, including issue threads.

## Security

Never file security issues in public. See `SECURITY.md`.

## License

By contributing, you agree your contribution is licensed under the same terms as the rest of the repo. The frontend layer license is finalized before Phase 5 ships — that decision will be reflected here when made.
